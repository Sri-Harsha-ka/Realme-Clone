# 📱 Realme Clone – Landing Page Replica  

A pixel-perfect **replica of the official Realme landing page**, built using **React + Tailwind CSS**.  
This project’s goal was to recreate the original Realme homepage **as accurately as possible**, focusing on layout, visuals, responsiveness, and UI precision.

---

## 🚀 Live Demo  
🔗 **Deployed Link:** https://realme-clone-d3an.vercel.app/

---

## 🛠️ Tech Stack  
- **React.js** – Component-based UI  
- **Tailwind CSS** – Utility-first styling  
- **Vite** – Fast development server & build tool

---

## 📌 Features  
- ✔️ Exact replica of the Realme official landing page  
- ✔️ Fully responsive layout  
- ✔️ Clean and modern UI  
- ✔️ Optimized images & assets  
- ✔️ Smooth UI structure using React components  
- ✔️ Styled completely with Tailwind CSS  

> Note: Only the **main landing page** (first page) is implemented. No backend or deeper navigation is included.

---

## 📂 Project Setup  

### 1️⃣ Clone the Repository
```bash
git clone https://github.com/Sri-Harsha-ka/Realme-Clone.git
cd Realme-Clone
```

### 2️⃣ Install Dependencies
```bash
npm install
```

### 3️⃣ Run Locally
```bash
npm run dev
```

Then open the local URL provided in your terminal.
